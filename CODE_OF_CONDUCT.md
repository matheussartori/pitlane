# Code of conduct

Pitlane follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep criticism about the work, and don't harass anyone. This applies in issues, pull requests, discussions and anywhere you represent the project.

To report unacceptable behaviour, contact the maintainer, [@matheussartori](https://github.com/matheussartori), privately. Reports are handled confidentially.
